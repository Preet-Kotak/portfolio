# 🏰 Preet's Portfolio — A Clash of Clans Village (Yes, Really)

Hey, I'm **Preetkumar Kotak**, a B.Tech CSE student at SVNIT Surat and I really could not bring myself to make a normal portfolio. So instead I built a Clash of Clans village where you click on buildings to learn about me. Was it overkill? probably. Did I have fun building it? absolutely yes.

---

## 🎮 What Even Is This?

When you first open the site you get to pick between two modes:

### ⚔️ Gamified Mode (the fun one)
An interactive CoC style village where each building does something. Click on them to explore:

| Building | What it opens |
|---|---|
| 🏛️ Town Hall | About me, bio, links |
| 🪖 Barracks | My skills |
| 🔨 Builder's Hut | My projects |
| 🧪 Laboratory | Achievements |
| 🏆 Trophy Button | Live coding stats |
| 💬 Chat Button | Chat bot or just contact me directly |

The village has the actual CoC background music, trees that sway, little soldiers walking around, smoke coming out of the army camps, a glowing gem box and a first time tutorial that walks you through everything. I went all out ngl.

### 💼 Professional Mode (the normal one)
A clean scroll down resume style page with the same gold colour theme, for when an actual recruiter is looking. Has a proper nav, project cards, contact form and everything you'd expect.

You can switch between the two any time and it remembers which one you picked.

---

## 🛠️ Built With

- **React** — for all the UI stuff
- **Phaser 4** — the game engine that powers the village
- **Vite** — build tool
- **Tailwind CSS** — styling
- **EmailJS** — so the contact form actually sends emails without needing a server
- **Codeforces, LeetCode and GitHub APIs** — live stats that update on every visit

---

## 🚀 Cool Things About It

- Two completely different experiences in one portfolio, a game and a resume page, you pick
- The village is sharp on every screen, nothing looks blurry even on high res displays
- Clicking a building opens a proper info panel and everything stays in sync
- My coding stats are live so the numbers are always up to date, no faking it
- Full CoC audio with intro music, background theme, sound effects and a mute button if you hate fun
- A chat bot that actually knows stuff about me, you can also use it to send me a message
- A guided walkthrough on your first visit that shows you what everything does then gets out of the way
- In professional mode the project cards stack up as you scroll which looks pretty cool
- Works on mobile too but its honestly better in landscape, it'll ask you to rotate if you're on portrait
